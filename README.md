# Trauma Center Second Opinon Archipelago
## THIS APWORLD IS UNSTABLE! EXPECT ISSUES & RELEASES TO OCCUR IF SOMETHING UNKNOWN GOES WRONG!
### Setup Guide
Download the latest release.
Install the APWorld
Generate a YAML file using the Options Creator
Whenever the seed is generated, FIRST OPEN DOLPHIN AND YOUR LEGAL NTSC COPY OF SECOND OPINION. Not following this can cause issues with the randomizer.
Once TCSO is open, launch the "Trauma Center Second Opinion Client" from the Archipelago Launcher and connect.
Type in the room code and get connected! You should see a "Seed Validated" message in your client once this is done.
Pick a new game, select your difficulty, and pick a save slot to play on. Your game should be properly randomized!
IF ANY ISSUES OCCUR IN WHICH YOU NEED TO RESTART TCSO, FIRST DISCONNECT FROM THE ROOM AND CLOSE THE CLIENT. THEN REOPEN TCSO, OPEN THE CLIENT FROM THE LAUNCHER, AND RECONNECT.
